01 / КАК УСТРОЕН СЛАЙС

Слайс — это не массив. Это описание массива.

Массив хранит значения. Слайс хранит, откуда начать, сколько видно и насколько можно расшириться.
Внутри Go runtime
type slice struct {
    array unsafe.Pointer
    len   int
    cap   int
}
Открыть исходник Go ↗
arrayАдрес начала. Указатель на первый элемент слайса, не обязательно на начало массива.
lenВидимая часть. Сколько элементов доступно по обычному индексу.
capЗапас вправо. Сколько элементов помещается от начала слайса в доступной области массива.
Один пример — вся модель
a := [5]int{10, 20, 30, 40, 50}
s := a[1:3]

В массиве пять чисел. Слайс s начинается с элемента 20, видит два элемента и располагает четырьмя позициями до конца массива.

Запомниarray указывает на a[1], а не на a[0]. len и cap считаются от этой точки.

Теперь заголовков два — s и b, но обе стрелки ведут к одному и тому же элементу массива. Присваивание копирует три поля, а не пять чисел. Изменение b[0] затронет и s[0].

Это внутреннее представление runtime, а не структура, которую можно объявить или использовать вместо встроенного типа []int. Поле array напрямую из обычного Go-кода недоступно.

03 / КЛЮЧЕВОЙ МЕХАНИЗМ

Что на самом деле делает append?

append возвращает новый заголовок слайса. Если ёмкости хватает, элементы добавляются в тот же базовый массив. Иначе выделяется другой массив и копируются элементы.

04 / ПРАВИЛА

Что важно для реального кода

Общий массив

Изменение s[i] видно через другие слайсы, которые ссылаются на тот же элемент массива.

Новая ёмкость

Полное выражение a[low:high:max] ограничивает cap значением max-low и помогает избежать перезаписи исходного массива через append.

Передача в функцию

Заголовок слайса передаётся по значению. Изменения существующих элементов обычно видны вызывающему коду; новый результат append нужно вернуть, если вызывающему нужен обновлённый слайс.

nil и пустой слайс

Оба могут иметь len == 0 и cap == 0, но только nil-слайс равен nil. JSON-кодирование без специальных настроек обычно различается: null и [].

Удержание памяти

Маленький подслайс может удерживать весь большой базовый массив. Если нужно сохранить лишь небольшой фрагмент надолго, сделай независимую копию.
